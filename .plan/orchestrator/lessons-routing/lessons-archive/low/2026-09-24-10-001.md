# Template-glob mutation scope makes declared_scope_reconciliation non-authoritative — re-derive concrete sets at dispatch

## Context

The carve campaign outlines (slice 030/070/080) declare mutation-scope entries as template globs such as `test/**/test_{unit}_{cluster}.py` and `test/**/_{domain}_{surface}.py` — placeholders that are expanded per run at dispatch time. The mechanical `declared_scope_reconciliation` check expands declared globs against the tree with pathlib, which does not perform brace expansion. Every template-glob declaration therefore lands in `globs_unexpandable`, drives `population_complete` to `false`, and flips the whole mechanical pass to `ambiguous: true` — regardless of how many concrete globs expanded cleanly (22 of 26 in the module-budget-campaign-completion run).

The 17 findings emitted were all `declared_scope_reconciliation` failures on the 4 unexpandable template occurrences, and the phase-4 Q-Gate reported `ambiguous` for the entire plan over a property the outline knew about all along. A zero from an ambiguous pass is a statement about what the check managed to read, never a clean negative — so the orchestrator-side q-gate-validation dispatch remains mandatory.

## Resolution

- Declare template globs deliberately: when a mutation scope is a per-run template (unit/cluster, domain/surface), treat `declared_scope_reconciliation` findings on those exact strings as the known cost of the template form, and rely on the plan's dispatch-time re-derivation (the carve campaign's D1 protocol) to resolve concrete sets — do not chase a clean `population_complete` by listing every concrete file up front.
- The closure claims that DO matter are untouched by the template form: projection (every literal declared write path is a step target) and referrer (every step target is declared) both passed with template globs in the surface, because the glob STRING is the declared path and step targets equal that same string.
- The phase-4 return TOON must still report `qgate_validation_required: true` when the compilation is ambiguous, and the phase aggregate must carry the 17 findings — an ambiguous mechanical pass is a hint that the LLM validators must run, never a licence to skip them.
