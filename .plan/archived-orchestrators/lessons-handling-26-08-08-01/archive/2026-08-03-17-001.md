# An aggregation states its predicate precisely and leaves the set it ranges over implicit - both review catches on one PR were this

## Observation

On PR #1086 **both** review-bot catches were the same defect, and self-review's finding was a third
instance of it:

| Finding | The predicate | The set left implicit |
|---|---|---|
| CodeRabbit **Major** | *"every `[...]` section is a phase"* | non-phase roll-up sections, which would have **inflated the corpus denominator** |
| CodeRabbit Minor | *"sum the undercount tallies"* | two **independent** tallies, so a plan tripping both was double-counted |
| Self-review | *"subagent `cache_read` lands in the residual"* | the code spread it across **named parent buckets** instead |

⭐ **Three independent detectors converged on one shape**, which is why the preference-emitter and
lessons-capture both surfaced it without coordination: **a new aggregation states its predicate
precisely and leaves the set it ranges over implicit.**

⛔ **The pre-existing tests passed against the first defect.** Nine tests now pin the three, including
**negative controls** — which is the part that mattered: a test that only exercises the intended
population cannot detect that the population is wrong.

## Rule

- **When adding an aggregation — a sum, a count, a share, a denominator — write down the SET it
  ranges over as explicitly as the operation.** *"Sum X"* is half a specification. *"Sum X over
  exactly the members of Y"* is the whole one, and the second half is where the defect lives.
- **Every new aggregate needs a negative control**: an input that is *near* the population but must
  be excluded, asserted excluded. Without it the test passes for a reason unrelated to correctness.
- ⭐ **A denominator is the highest-risk aggregate**, because an inflated denominator produces a
  smaller, more reassuring share — the defect direction is toward false comfort.
- This is the population-derivation rule (see the sibling lesson on named site lists being samples)
  applied at authoring time rather than at remediation time. **Same failure, one step earlier.**

## Impact

`manage-metrics` billing parser, `audit-archived-plan-retrospectives`'s
`billing-composition_undercounted`, and every aggregation in the retrospective/metrics surface. The
concrete fixes shipped in PR #1086.
