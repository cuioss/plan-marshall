# A test-side mirror of a source-defined set is pinned to a published seam, not necessarily hoisted into the source

CodeRabbit flagged a `ROUTES` table in `test_credentials_cli.py` as duplicating
the delegated command branches in `credentials.py`: add a branch there without a
row here, and the suite stays green while the new route is neither stubbed nor
tested. The flagged rule is real and standing — a hardcoded list mirroring a set
defined elsewhere is a defect unless derived from that source.

The reflexive remedy is to hoist the registry into the source and import it. That
was the wrong move **here**, and the reason generalizes.

## Why the source-side half was declined

`credentials.py` resolves each handler through a **function-local import inside
the branch**, and that is a deliberate seam documented in the test module's own
docstring: it is what lets a `monkeypatch` on the owning module reach the binding
the branch resolves at call time. A module-level registry would import all ten
handlers eagerly at module load, defeating the seam and breaking every test in the
file. The duplication the reviewer saw was the visible cost of a design decision,
not an oversight.

## Solution

Close the drift **test-side**, against a seam the source already publishes. Here
the source exposes `build_parser()`, so a new assertion pins the published
subcommand set to `ROUTES` plus the one non-delegating route (`migrate-home`):
an eleventh branch added to `credentials.py` now fails that assertion instead of
passing silently. The mirror survives, but it can no longer drift undetected.

The general rule: a drift-detection finding asks for *a check that fails on
drift*, not specifically for *deduplication*. When the duplication is load-bearing
for a deliberate seam, satisfy the finding by adding the check rather than by
removing the duplicate.

## Impact

Record the declined half with its reason, in the PR response and in the code. A
split verdict that says only "fixed" invites the next reviewer — human or bot — to
re-raise the source-side half, and the seam rationale has to be reconstructed from
scratch each time.
