# Twin comparisons over one declaration vocabulary must share one containment rule

Source: implement-plan-05-declaration-currency (tooling-truthfulness), PR #1482.
Fixed in-run (6af1753) with focused tests — the principle is the durable part.

## Problem

`compute_surface_delta` used exact set subtraction while the D1 comparison it
twins is containment-aware, so a realized file beneath a declared `test/` or
`test/**` entry reported a false landing expansion.

## Guidance

Two comparisons over the same declaration vocabulary must share one containment
rule; an exact-subtraction twin of a containment-aware comparison
false-positives on every directory claim. When adding a second comparison over
an already-compared vocabulary, import the rule — never re-derive the
comparison.
