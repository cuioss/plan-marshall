# Two vacuous plan-dir presence assertions in test_manage_status_transition_archive.py

`conftest.plan_context.plan_dir_for(plan_id)` CREATES the directory it returns
(`mkdir(parents=True, exist_ok=True)`), so any assertion built on it about that
directory's PRESENCE or ABSENCE is decided by the probe rather than by the code
under test. An earlier plan hit the absence direction and fixed it (probing
`plan_context.plans_dir / plan_id` instead, a pure path join that reads the
filesystem without touching it).

The PRESENCE direction is still live in
`test/plan-marshall/manage-status/test_manage_status_transition_archive.py`:

- line 331, `test_archive_refuses_when_actionable_finding_pending`
- line 423, `test_archive_gate_fires_when_finalize_is_open_but_not_current`

Both assert `plan_context.plan_dir_for(plan_id).exists()` to prove "the refused
archive moved nothing". Both are vacuously true: the helper materializes the
path immediately before `.exists()` is read, so each would still pass if the
refusal regressed and the archive DID move the plan directory.

## The fix

Same one-line shape as the earlier fix: build the probe as
`(plan_context.plans_dir / plan_id)`, a pure path join that reads the filesystem
without touching it, instead of `plan_context.plan_dir_for(plan_id)`.
