# Never reconstruct a full commit SHA from an abbreviated one - read it from git rev-parse HEAD

## Directive

When appending a `commit_sha` to the change ledger — or any audit store — obtain it with `git rev-parse HEAD`. **Never reconstruct a 40-character SHA from the abbreviated form git prints in commit output.**

## Observed

PLAN-TRUTH-114, 2026-08-27. An execution-context leaf expanded the abbreviated `ded6b7ef0` into:

```
ded6b7ef07d1b1cd7cd47b8fa2d02e2c0dbf17dd   <- invented
ded6b7ef07f37f5f27b18db2bf7518bf02dc2d28   <- real
```

Correct for exactly 9 characters, invented for the remaining 31.

## Why this failure mode is especially dangerous

**The prefix matches.** A reader spot-checking the first few characters, or searching by short SHA, finds agreement and concludes the row is sound. It is the same corroborating-coincidence shape as an equal-but-wrong count: the check a careful reader would run is the one that passes.

## Why it cannot be undone

The change ledger is **pure-append** — `append` and `query` only, no update verb. A wrong row can never be withdrawn. The only mitigation is appending a corrected row plus a WARNING decision-log entry naming the later row as authoritative.

## The live hazard that leaves behind

Any consumer that resolves a deliverable to a commit by reading the **first** matching row gets a commit that does not exist.

And shape alone cannot distinguish a correction from a re-run: duplicate `deliverable_id` rows are legitimate and common (a follow-up commit on the same deliverable — `deliverable_id` 3 and 4 each appear twice in this plan's ledger for exactly that reason). So a consumer **must take the LAST row for a `deliverable_id`, not the first**.

Auditing every ledger consumer for first-match-wins resolution is worth doing.

## Credit where due

The leaf self-disclosed this unprompted rather than letting it pass. That is the behaviour to reinforce — a fabricated value that is voluntarily surfaced costs one corrective row; one that is not, corrupts an append-only audit trail silently.
