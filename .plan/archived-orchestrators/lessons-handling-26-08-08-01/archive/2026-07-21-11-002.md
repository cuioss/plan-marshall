# Worktree materialization branches off local main without asserting local main == origin/main, silently inheriting a foreign unpushed commit into the plan branch

## Symptom

This plan's feature branch carried a commit the plan never authored. The
foreign commit was lessons-housekeeping work that a DIFFERENT concurrent
session had committed to the local `main` ref and left unpushed. When
`prepare_execute` materialized this plan's worktree, it branched from the
local `main` tip — which at that moment was one commit ahead of
`origin/main` — so the plan branch inherited that commit as part of its
baseline.

Nothing surfaced the contamination during phases 5 or the early part of 6.
It only became visible at the `finalize-step-sync-baseline` rebase, which
reported `overlap_with_content_conflict`: the same content had independently
landed on `origin/main` via the other session's own PR, so the inherited
commit now conflicted with the upstream version of itself.

## Root cause

Worktree materialization at phase-5 takes the local `main` ref as its
branch point with **no assertion that `main` is in sync with
`origin/main`**. On a single-session machine that assumption almost always
holds, so the gap is invisible. It breaks precisely in the multi-session /
multi-worktree mode this project routinely runs in: any concurrent session
that commits to local `main` before pushing widens the window in which a
newly-materialized worktree inherits work that is not its own.

The failure is silent by construction. An inherited commit is a perfectly
ordinary ancestor commit on the branch — `git log`, `git status`, and every
phase-5 gate treat it as baseline. There is no phase-5 or early-phase-6
check that compares the plan branch's merge-base against `origin/main`.

## Impact

- The plan's PR diff misrepresents the plan's authorship: it contains
  changes the plan never made, which pollutes review, the changed-file
  footprint, and any footprint-driven build/step gating computed from it.
- The contamination detonates at the LATEST possible moment — the finalize
  sync-baseline rebase, after the PR already exists — where recovery is most
  expensive and most likely to be misdiagnosed as ordinary baseline drift.
- When the concurrent session lands the same content upstream first (the
  case here), the conflict is a confusing self-conflict: identical content on
  both sides, with no obvious "who wrote this" signal.

## Corrective action

**Guard at materialization (the real fix).** Before branching a plan
worktree from local `main`, assert that local `main` and `origin/main` agree
— fetch, then compare the refs. On divergence, do not silently proceed:
either branch from `origin/main` explicitly (the safest default, since a
plan's baseline should be the shared upstream, never another session's
unpushed local state), or fail loud with the divergence reported so the
operator can decide. The `git -C {worktree}` branch-creation call site in
`prepare_execute` is where this belongs; a divergence check there is cheap
and runs once per plan.

**Recovery when it has already happened.** The remedy used in this run and
worth keeping documented: rebase the plan branch to drop the foreign
ancestry rather than trying to resolve the self-conflict hunk by hunk.

```bash
git rebase --onto origin/main <foreign-sha>
```

where `<foreign-sha>` is the inherited commit. This replays only the plan's
own commits onto the current upstream, discarding the foreign commit from
the branch entirely (it is already on `origin/main` via the other session's
PR, so nothing is lost).

## Recurrence signature

A `finalize-step-sync-baseline` rebase reporting
`overlap_with_content_conflict` where the conflicting content is IDENTICAL
on both sides and the plan has no memory of authoring it. Confirm by
checking whether the plan branch's merge-base with `origin/main` is older
than the branch's first plan-authored commit — if there is a commit between
the merge-base and the plan's first commit, it was inherited, not authored.
Distinguish this from ordinary baseline drift (lesson 2026-06-24-14-001),
where the conflicting content genuinely differs and the plan did author its
side.
