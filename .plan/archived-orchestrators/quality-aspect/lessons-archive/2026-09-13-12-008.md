# A uniform-shape instruction over an enumerated set is checked member-by-member, or it silently drops the exceptional member

Deliverable 2 enumerated all 11 `main()` routes in `credentials.py` and instructed
"one exercise per route ... asserting that each dispatches to its own handler",
plus "patch each `run_*` handler so no route performs real credential or network
I/O". Checked against the source, ten routes do dispatch to a `run_*` handler and
one — `migrate-home` (credentials.py:197-205) — dispatches to none: it calls
`_providers_core._migrate_credentials_home_if_needed()` and
`file_ops.output_toon` inline and returns 0.

So the stated assertion shape was false for that member, and the stated patch
target did not exist for it.

## Why this is worse than an ordinary inaccuracy

The instruction was *self-consistent and complete-looking*: it named the right
count (11), the right file, and a real mechanism. An implementer following it
literally has only two moves at `migrate-home` — write an assertion that cannot
hold, or quietly skip the route. Both leave the branch uncovered, and the second
leaves the coverage deliverable reporting success over the exact branch it was
written to reach. The exceptional member is never a random one: it is the
oddly-shaped branch, which is precisely the branch most likely to be buggy and
least likely to be covered already.

## Solution

Before writing a universal claim over an enumerated set ("each X ...", "every
route ...", "all N handlers ..."), walk the set in the source and confirm the
shape holds for **every** member. When one diverges, split the instruction into
its real branch shapes and name the outlier's actual seam — here, ten
import-and-return-a-handler routes plus `migrate-home` exercised at
`_migrate_credentials_home_if_needed` and `file_ops.output_toon`, asserting its
payload and `return 0`. Update the success criterion in the same edit so a literal
reading still covers the whole set.

The sibling rule for *value* enumerations already exists in
`persona-plan-marshall-agent/standards/agent-behavior-rules.md` ("Never assert
closure over an enumeration without re-checking it against its declaring source").
This is the same discipline applied to a claimed uniform SHAPE over a set of code
paths rather than to a claimed complete LIST of legal values.

## Impact

Every outline that plans per-branch test coverage from a route table, a dispatch
chain, a handler registry, or a subcommand set. Note the isolation was never at
risk here (`conftest.py` already sandboxes the credential dir) — the defect was in
the instruction, and a fix aimed at the isolation would have missed it entirely.
