# Report the classified unevaluated state, never a row-builder default

Source: implement-plan-05-declaration-currency (tooling-truthfulness), PR #1482.
Fixed in-run (6af1753) with a regression test — the principle is the durable part.

## Problem

Declaration-currency reported every unevaluated spec row as `unreadable`,
collapsing the `absent` (declared no surface) versus `unreadable` (could not
read) distinction that `_surface_state` returns.

## Guidance

A row-builder default that overwrites a classified state destroys the
classifier's vocabulary downstream; report the classified state and let
consumers decide. Collapsing `absent` into `unreadable` is the same failure
this epic exists to close — a could-not-evaluate reported as a (different)
evaluated result.
