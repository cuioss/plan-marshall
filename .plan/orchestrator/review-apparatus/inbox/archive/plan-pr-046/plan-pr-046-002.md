# Report a post-merge empty base-ref diff as indeterminate, not as a failed check

component: plan-marshall:plan-retrospective
category: bug
confidence: high

## Context

The retrospective ran after PR #1477 had already squash-merged into main and the branch had been pruned. `check-manifest-consistency` resolved its diff against `origin/main`, got zero files, and reported the `branch_cleanup_changes` rule as **fail** with the message "the footprint resolved to no changed path at all, so no implementation file changed" — on a plan that changed 31 files. In the same run, `check-outline-vs-shipped` resolved 31 realized paths through the shared footprint resolver, and `check-artifact-consistency` recovered 19 of 20 declared files. Three aspects, one plan, two mutually contradictory footprints.

## Root cause

`check-manifest-consistency` obtains its footprint from a base-ref diff rather than from the shared footprint resolver its sibling aspects use. After a merge the `origin/main..HEAD` range is legitimately empty, so the script cannot distinguish "this plan changed nothing" from "this comparison is no longer possible". It then publishes `diff_available: true` and grades a rule that had no evidence, which is the could-not-look-reports-a-verdict shape rather than the `indeterminate` the script already supports for the no-base-ref case.

## Proposed action

Route `check-manifest-consistency`'s footprint through the shared footprint resolver, as `check-routing-decisions` and `check-outline-vs-shipped` already do. Failing that, when the base-ref diff resolves empty **and** the shared resolver returns a non-empty footprint, report every diff-fed rule as `indeterminate` with a reason naming the merged-base condition — never as a pass and never as a fail. A retrospective that runs at finalize order 995 will always see this state on a plan whose branch-cleanup step merged first.

## Evidence

- aspect: manifest_decisions — `diff.files_total: 0`, `diff_available: true`, check `branch_cleanup_changes` = fail
- aspect: outline_vs_shipped — `footprint_source: resolved`, `footprint_path_count: 31`
- aspect: artifact_consistency — `affected_files_recall` 19 of 20 found, `footprint_resolved: true`
