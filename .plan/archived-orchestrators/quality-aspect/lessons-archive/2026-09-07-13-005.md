# Two documented automatic-review invocations do not survive their own runtime

## Context

Two invocations that `automatic-review`'s own documentation prescribes fail when executed as
written. Both were hit during plan `plan-04-autonomy-gate-defaults` (epic `operator-ux`, PR #1437).

**1. Branch A's `mark-step-done` snippet omits `--force`.** Every terminal pass that follows a
loop-back therefore hits `error: conflict`, because the step already carries a recorded outcome.
Hit **twice** in this one run. A loop-back is the ordinary path for this step, not an edge case, so
the documented snippet is wrong on the common case.

**2. `review_completeness.py check` rejects the invocation its own SKILL.md documents.** The template
interpolates `--measured-diff-size` unconditionally while the flag takes a required value, so the
call fails on the common path where no bot refused for size.

## Root cause

Both are worked examples that were never executed against the runtime they document. A snippet in a
skill body is a contract the dispatched leaf follows literally — it has no way to know the example
omits a flag the runtime requires.

## Proposed action

1. Add `--force` to the Branch A snippet, or make `mark-step-done` idempotent for an unchanged
   outcome so the terminal pass needs no flag.
2. Make the `--measured-diff-size` interpolation conditional, or give the flag a default that
   encodes "not measured".
3. Structurally: a documented invocation is a testable artifact. The corpus already asks for the
   declared accept-set to be published (`2026-09-04-17-008`); the complement is asserting each
   documented snippet parses against it.

## Impact

⛔ **Defect 2 is the THIRD recorded instance of `2026-08-25-09-014`** (*`review_completeness
--measured-diff-size` is the one flag the empty-is-safe guarantee does not cover*), which is already
`finalize-machinery` decompose input at 2 instances. The PLAN-03 landing recorded the second. Three
independent agents have now hit the same documented-versus-actual mismatch, so the recurrence rate
is the finding, not the flag.

Both defects are unfixed and were carried to the epic rather than patched, correctly — they are
machinery this plan does not own.
