# finalize-step-lessons-housekeeping documents the retired modified_files reference field instead of the compute-footprint resolver

## Observation

Step 1 of `.claude/skills/finalize-step-lessons-housekeeping/SKILL.md` instructs `manage-references get --plan-id {plan_id} --field modified_files`. That field is retired: the verb answers `field_retired` and names the live resolver instead.

## Impact

The step's first classification input — what the plan changed — is unobtainable as documented, so the coverage classification starts from an empty footprint. A later reader cannot tell a plan that changed nothing from a step that failed to read the footprint.

## Directive

Replace the retired `--field modified_files` call in Step 1 with `manage-references compute-footprint --plan-id {plan_id} --worktree-path {worktree_path}` (the `--worktree-path` flag is required), and keep the request read. Add a guard so a step that cannot read the plan footprint reports it rather than classifying against an empty set.
