# 2026-09-06-07-003 — Trigger-B selects one bot by newest finding and cannot reach a different stale bot

component: plan-marshall:automatic-review

status: moved-to-epic (corpus original retired 2026-09-17: completely_covered by PR #1510)

## Context

Trigger-B prose: remedy for a stale bot. Implementation: selects target from the NEWEST
bot-authored finding's kind — by construction the least-likely-stale bot. Bot A current
+ bot B behind → fires for A, B stays stale (three hand-issued /review triggers needed
on the observed run). Recurrence PR #1476: selected coderabbit, left required
cuioss-review-bot stale; second half showed the in-place update arriving as
`matched/unverified` (the 08-22-001 discriminator defect) misread as decline.

## Root cause

Selector answers "who most recently spoke" for a purpose that needs "who has not spoken
about this head". Deriving the target from the findings store (who DID review) is the
error.

## Proposed action

Select from per-bot currency state (`bot_states` reviewed-head records); fire per member
of the stale set, not one trigger; never fall back to newest-finding heuristic — report
indeterminate instead.

## Coverage (finalize-machinery)

Remedy shipped by PLAN-03 / PR #1510: `review_completeness.py` selects the actually-stale
bot via `select_stale_bot_for_trigger`. Corpus original retired as completely_covered.
