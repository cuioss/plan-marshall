# A rendered footer named one reserved provenance while its own docstring named two

Source: PR #1489 CodeRabbit inline finding 8018ea (resolution=fixed, TASK-037).

The shared declared_note said "any dependency listed above is declared", while the same
function's docstring four lines above states that declared internal_dependencies AND
sibling-cross-link are BOTH reserved non-resolver sources, and that both branches are
qualified symmetrically. The rendered string and the contract it implements disagreed
about the same set — four lines apart.

## Solution

Reword the note to cover both provenances, and update the two assertions in
test_derivation_resolver_configuration.py to pin the corrected wording.

The pattern: a user-visible string that summarises a set defined immediately above it is
a restatement, and restatements drift. Either derive the string from the set, or pin it
with a test that reads the set.

## Impact

The footer is what a user reads to learn where an edge came from; naming only one of two
sources mislabels every sibling-cross-link edge.
