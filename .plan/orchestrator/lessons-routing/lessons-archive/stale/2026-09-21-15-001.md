# Phase-transition artifact gate must require regular files, not mere existence

CodeRabbit finding 878984 (PR #1540, inline on `marketplace/bundles/plan-marshall/skills/manage-status/scripts/_cmd_lifecycle.py:243`) showed `_has_plan_artifact` accepted directories as artifacts: `Path.glob('TASK-*.json')` matches directories and `Path.exists()` is true for directories, so a `tasks/TASK-001.json/` directory or an `execution.toon/` directory satisfied the gate and `cmd_transition` advanced the plan to `5-execute` without the required file.

## Solution

Fixed via TASK-6 (commit b72e26f4c) following the bot's proposed diff: filter task matches with `is_file()` and check `execution.toon` with `is_file()`, plus directory regression cases.

## Impact

Any phase gate that checks for artifact presence with `glob()` + `exists()` is vulnerable to the same directory-masquerade bypass. Prefer `is_file()` at every existence check that guards a transition.
