## The defect

The commit-permalink widening (contract ~line 466) is implemented only on the review
signal's evidence. PR-Agent publishes only `issue_comment`, so the review path finds
nothing and `head_sha_verified` is false on every run — e.g. a body naming exactly the
awaited HEAD permalink still returned false (PR 1455). Under the literal re-review arm
this classifies as incremental-review decline every re-review, steering away from the
retry that would expose it. Adjacent case: an in-progress marker naming the HEAD is not
a decline either — completion-aware poll is the route.

## Directive

Extend permalink recognition to the comment evidence path; re-read in-progress markers
as pending, not declined.

## Coverage (finalize-machinery)

Same comment-path repair as 14-001, shipped by PLAN-03 / PR #1510. Corpus original
retired as completely_covered.
