# review_completeness rejects bare bot names in --stale-participation-bots

component: plan-marshall:automatic-review
category: anti-pattern
status: active

## Rule

Always pass `--stale-participation-bots` entries as `bot_kind:evidence_kind`
pairs (e.g. `cuioss-review-bot:<evidence>`); never a bare bot name. A bare
bot_kind carries no evidence kind, so silently dropping it would resolve the
bot to absent (a blocking state prescribing escalation) instead of
participated_stale (whose remedy is a re-review trigger) — hence the
fail-closed rejection as a caller error. The fail-closed shape is deliberate
and must not be "fixed" by loosening the parser.
