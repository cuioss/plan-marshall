# Do not use an exact test-count match between builds as evidence about a change: generator-driven parameterized tests move the total

Source: PLAN-V02-50 (#532), candidate lesson 002.

## Observation

The reported total test count moved between otherwise identical builds. The drift came from generator-driven parameterized tests (CUI Test Generator, `@GeneratorsSource`) whose invocation count varies per run, not from tests being added, dropped or skipped.

## Rule

- Do not read an exact total-count match, or mismatch, between two runs as evidence that a change did or did not affect the suite.
- Compare by test class and by failure set. Treat a small delta confined to generator-sourced parameterized tests as expected noise.
- Investigate a delta only when it maps to a missing or newly skipped test class.

## Apply

Any plan or review that cites a before and after test count as proof (a simplification plan, a test move, a "no tests lost" claim). Quote class counts, not the grand total.
