title: review_completeness check --measured-diff-size rejects its own documented invocation on the common path
content: "## Problem

`review_completeness check` declares `--measured-diff-size` as an ordinary value-taking flag — it is the only flag in that block without `nargs='?'` / `const=''`. Meanwhile:

- the producer returns `measured_diff_size: \"\"` whenever no size-based refusal occurred, which is the **common** case; and
- the executor strips empty arguments before dispatch.

So the SKILL.md-documented invocation, populated from a normal (non-refusing) producer return, arrives at argparse as a bare `--measured-diff-size` with no value and **exits 2**.

Observed on PR #1454 (plan `pre-push-gate-mutation-coherence`).

## Why it matters

The exit-2 lands on a **completeness gate**. Under the UNKNOWN-verdict rule an argparse rejection must never be read as a pass — so the correct handling of this failure is to refuse, which means the defect manifests as a **live false-blocker on the happy path**: a run where every bot participated cleanly cannot get a clean verdict out of the verb.

It is also a documentation-contract divergence: the command as written in SKILL.md does not run. The SKILL.md prose does carry an empty-argument guarantee, but it is scoped to *\"every list flag\"* — `--measured-diff-size` is a **scalar**, so it slips the guarantee's wording while sharing the exact failure mode the guarantee exists to prevent.

## Directive

1. **Give `--measured-diff-size` the same `nargs='?'` / `const=''` treatment its sibling flags have**, so an empty producer value is accepted rather than rejected.
2. **Widen the SKILL.md guarantee from \"every list flag\" to every flag that can receive an empty producer value**, scalars included. The current wording is what let a scalar be added without inheriting the property — fix the rule, not just this instance.
3. **Sweep for other scalars in the same block** that can receive an empty producer value and are missing the treatment. Derive that set from the producer's return shape rather than by eye; this flag was the only one, but the sweep is what establishes that rather than assumes it.
4. **Regression test**: invoke the documented command with the producer's non-refusing return and assert exit 0 — the test must exercise the empty-value path, since the populated path already passes.

## Evidence

- `marketplace/bundles/plan-marshall/skills/automatic-review/` — `review_completeness check`, the `--measured-diff-size` declaration and its sibling flags
- `marketplace/bundles/plan-marshall/skills/automatic-review/SKILL.md` — the \"every list flag\" empty-argument guarantee whose scope excludes this scalar
- `marketplace/bundles/plan-marshall/skills/tools-script-executor/` — the executor's empty-argument stripping"
