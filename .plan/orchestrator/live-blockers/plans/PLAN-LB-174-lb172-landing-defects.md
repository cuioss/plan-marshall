## Objective

PLAN-LB-172 merged all ten of its deliverables and its landing analysis found three majors in the code it shipped, each a fail-open: a routed build whose log fails after the child ran renders as an ordinary red build with its reason lost; the Sonar carry-forward binding holds only when the caller passes an optional field, so a caller that drops it still gets a plain passing verdict; and a review-body section whose only content is a fenced suggestion reads zero findings. This plan closes the three, and the minors the leaf found beside them, grouped by module: the routed build client, the Sonar gate and facts, the review-body parser, the CI footprint discovery, the execution manifest with `manage-config`, and the analyze contract documents with their tests.
