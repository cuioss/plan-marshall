# ci router-scoped --plan-id belongs BEFORE the verb, never after pr

# ci router-scoped --plan-id belongs BEFORE the verb, never after pr

component: plan-marshall:tools-integration-ci
category: anti-pattern
status: active

## Rule

On the `ci` surface `--plan-id` is a top-level router flag consumed before
the subcommand verb; placed after the verb it reads as an unrecognized
argument. Read the canonical-invocation block per verb: pre-verb `--plan-id`
only for the router-consumed read verbs (`checks`, `pr view`, `pr list`,
`pr wait-for-comments`), post-verb where the subparser declares its own
required `--plan-id` (body consumers, prepare-body/prepare-comment), nothing
where it is undeclared. Never append `--plan-id` by rote.
