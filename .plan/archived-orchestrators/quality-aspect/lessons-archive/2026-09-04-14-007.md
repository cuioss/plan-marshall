# references.json carries no plan_creation_sha, so scope_creep_check compares nothing

## Context

During finalize of `plan-145-publish-the-missing-parser-seams`, the `scope_creep_check` returned `could_not_look` with reason `no_baseline_sha`. The cause is that `references.json` carries no `plan_creation_sha` field:

```text
python3 .plan/execute-script.py plan-marshall:manage-references:manage-references \
  get --plan-id plan-145-publish-the-missing-parser-seams --field plan_creation_sha
-> status: error / error: field_not_found
```

The check ran, compared nothing, and produced no finding. Reading its output without reading its `could_not_look` discriminator gives exactly the fail-open this project has closed in `manage-lessons list-stalled`, `restore-from-plan`, `manage-findings`, and `check-outline-vs-shipped` — a guard that could not look reporting indistinguishably from a guard that looked and found nothing.

On this plan the omission was benign (the realized footprint was 3 files against 2 declared), but nothing in the run established that; the guard simply had no baseline commit to diff against.

## Root cause

`plan_creation_sha` is never written into `references.json` at plan creation, so any consumer that needs the plan's baseline commit has no anchor. `scope_creep_check` correctly refuses to invent one and correctly reports `could_not_look` — the defect is upstream, in the writer.

A related, separate gap on the same file: `affected_files` held 2 paths while the merged commit touched 3 (`test/plan-marshall/script-shared/test_conftest_loader_contract.py` was never appended). That understates every metrics denominator derived from it — `files_modified: 2` — so `tokens_per_file_modified` is roughly 1.5x too large on this plan.

## Proposed action

1. Write `plan_creation_sha` into `references.json` at plan-1-init, recording the `main_sha` the plan was created against. The value is already captured in the phase-1 handshake invariants (`main_sha`), so this is a persist, not a new measurement.
2. Make `scope_creep_check`'s `could_not_look` verdict visible in the finalize output rather than folded into a clean pass — a gate that compared nothing must not render as a gate that passed.
3. Ensure the realized footprint is appended to `affected_files` so the metrics denominators match the shipped change (see lesson `2026-08-25-09-001`).
