# shutil.copyfile into a possibly-symlinked destination writes through the stale link, unlink first before copy, only the PR bot caught it

## Context

Plan `fix-executor-preflight-staleness-signaling` added a copy step to
`.claude/skills/sync-plugin-cache/scripts/sync.py` that copies the top-level
`target/claude/dist-manifest.json` sentinel into the plugin-cache root so
`generate_executor preflight` can resolve a real installed version. The new
sink wrote the file with a bare `shutil.copyfile(source_manifest, dest_manifest)`
into `cache_root / DIST_MANIFEST_FILENAME`.

## Defect

`shutil.copyfile` opens the destination for writing and **follows symlinks**.
If `dest_manifest` already exists as a (stale) symlink, the copy writes
*through* the link and clobbers the link's target — corrupting an unrelated
file — instead of replacing the manifest. The same shape is TOCTOU-unsafe: the
window between checking the destination and opening it for write lets the path
change type underneath the operation.

No in-house gate caught it — plugin-doctor, module-tests, and the quality-gate
all passed. Only the PR review bot (gemini-code-assist, medium priority) flagged
it on PR #853. This is the same "slipped past every in-house gate, only the PR
bot caught it" recurrence family as lessons `2026-06-22-13-001` and
`2026-06-30-15-001`.

## Corrective action

Before copying a file into a destination that may already exist — especially
cache roots, generated-output directories, and other reused sink paths —
proactively unlink it first:

```python
cache_root.mkdir(parents=True, exist_ok=True)
dest_manifest = cache_root / DIST_MANIFEST_FILENAME
dest_manifest.unlink(missing_ok=True)   # break any stale symlink; shrink the TOCTOU window
shutil.copyfile(source_manifest, dest_manifest)
```

`unlink(missing_ok=True)` removes a stale symlink so the subsequent copy creates
a fresh regular file rather than writing through the link, and it collapses the
check-then-write window down to the copy itself. An atomic
write-to-tmp-then-`os.replace` is the equivalent hardened alternative.

## Recurrence surface

Applies to every file-copy / file-write sink in the meta-project's sync and
generate scripts that writes into a **reused** destination path — the
`sync-plugin-cache` engine, the multi-target generator, and executor
generation. When authoring or reviewing such a sink, confirm each
`shutil.copyfile(` / `shutil.copy(` / open-for-write into a fixed dest either
unlinks first or uses an atomic replace. Direct copies into a possibly-symlinked
destination are CWE-59 (link following) hazards that no structural in-house gate
flags today.
