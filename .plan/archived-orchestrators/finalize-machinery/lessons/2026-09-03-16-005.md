## Observation

Handshake exited 1 on `pending_findings_blocking_count` captured "1" vs observed "0" —
a Q-Gate finding legitimately resolved between capture and handshake. Recurrence in the
same run showed the OPPOSITE direction (captured "1" observed "3" via Q-Gate re-entry
adding findings) — so the defect is not a direction but the capture point: snapshot and
live count straddle a re-entry. Direction-based relaxation must NOT be implemented (would
license half a two-sided defect).

## Recommended rule

Re-capture the invariant after the phase's own gate-resolution step rather than before
it. Related: 19-006 (verify exits non-zero with empty stderr — this class logs nothing
triagable).
