title: A prose instruction telling the agent to escape untrusted text is not an injection control
content: "## The rule

Untrusted external content — bot comment bodies, issue text, web page text, Sonar messages — must **never reach a shell argument vector**, and ⛔ **a documented escaping instruction addressed to the agent does not make it safe.**

Two acceptable remedies, in order of preference:

1. **Delete the interpolation.** If a structured, non-shell surface already carries the same facts, the shell-bound copy is redundant — remove it rather than quoting it.
2. If the value genuinely must cross a shell boundary, pass it through a mechanism that cannot be re-parsed as syntax (a file, an env var read by the callee, a structured payload), never by composing it into a quoted argument.

## Why the prose control fails on its own terms

PR #1477 (`plan-pr-046`), CodeRabbit finding `f0931a` — Major, Security & Privacy, CWE-78 (OS command injection), reachability External.

`automatic-review/SKILL.md` carried an ARMED decision-log template interpolating `{body}` — the refusal excerpt published by a review bot, i.e. untrusted external text — into a single-quoted `--message` shell argument. The document *did* carry a mitigation: prose instructing the agent to rewrite any embedded single quote.

⛔ **That control is prose addressed to an LLM, asking it to escape untrusted text at composition time.** And the character that breaks the quoting is an **apostrophe** — ordinary English punctuation that appears in routine bot prose. So:

- the failure fires on **normal** input, not only adversarial input; and
- the only thing between a bot's message and shell syntax is whether the model remembered to apply a documented step.

A control whose enforcement is the model's recall is not a control. It is a hope with a docstring.

## The fix that was taken, and why it generalises

TASK-011 did **not** harden the escaping. It **removed the `{body}` placeholder from the template**, because the skill already carried the same four facts as a structured `rate_window_arming[]` row on the returned envelope — a surface that needs no shell quoting and is what a resumed run actually reads back.

⭐ The generalisable move: when a dangerous interpolation exists, first ask whether the value is already carried somewhere safe. Redundancy is the cheapest vulnerability to remove.
