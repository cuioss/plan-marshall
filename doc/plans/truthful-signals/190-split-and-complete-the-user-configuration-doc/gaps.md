## G1 — Remove the retired `drop_review_on_scope_gate` row from the merge-knob table

- **Kind:** stale-statement
- **Severity:** high
- **Where:** `doc/user/parallelism-and-locking.adoc:55` — table row `steps['default:pre-submission-self-review'].drop_review_on_scope_gate`
- **What is wrong:** The row documents `drop_review_on_scope_gate` as a live, settable step-owned param with default `false`. The knob does not exist: `grep -rn drop_review_on_scope_gate marketplace/bundles/` returns **nothing** — it is absent from `get_default_config()`, from `data-model.md`, and from every step's `configurable:` frontmatter. It was removed by `8cd280a3` (an ancestor of this plan's commit), and two tests assert its absence outright — `test/plan-marshall/manage-config/test_config_defaults.py:345` and `test/plan-marshall/manage-config/test_sync_defaults.py:416`, both `assert 'drop_review_on_scope_gate' not in …`. This plan moved the row verbatim out of `configuration.adoc` into `parallelism-and-locking.adoc` and cited it in `report-01.md` § D6 as evidence the move was faithful. A sweep of all 76 table key cells across both pages found this as the only orphan.
- **Why it matters:** `_cmd_step` (`marketplace/bundles/plan-marshall/skills/manage-config/scripts/_cmd_quality_phases.py:324-347`) validates the *step id* but accepts any `--param` name without checking it against a known-param list. An operator following this table and running `manage-config plan phase-6-finalize step set --step-id default:pre-submission-self-review --param drop_review_on_scope_gate --value true` gets a success return and a persisted `marshal.json` key that nothing reads. The documentation makes a dead write look like a configuration change — a false signal shipped to the operator, which is exactly this epic's archetype.
- **Fix:** Delete the `drop_review_on_scope_gate` table row at `doc/user/parallelism-and-locking.adoc:55`. Nothing else in either page references the knob, so no surrounding prose needs adjusting. While in the file, note that the row is also mis-homed — it is a `default:pre-submission-self-review` param sitting in a table whose own following NOTE (`:58`) enumerates "All `default:branch-cleanup` step params" and does not list it.
- **Done when:** `grep -rn drop_review_on_scope_gate doc/` returns no hit outside `doc/plans/`, and the merge-knob table contains only params that resolve to a real key in `get_default_config()` or `data-model.md`.

## G5 — Reconcile `set-lane`'s accepted set with the per-element override validator (carried-forward residue)

- **Kind:** bug
- **Severity:** low
- **Where:** `marketplace/bundles/plan-marshall/skills/manage-config/scripts/_cmd_finalize_steps.py:68` — `_RESOLVED_ASK_LANE_VALUES`; the argparse `choices` at `manage-config.py:749`
