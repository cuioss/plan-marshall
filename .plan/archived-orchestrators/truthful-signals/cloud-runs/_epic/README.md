# truthful-signals

Plans staged for standalone execution from the `truthful-signals` epic.

**Theme:** a tool, gate, or hand-off reports a confident clean/complete signal while silently
suppressing the caveat that makes it wrong — plus the adjacent family in which machinery silently
loses information it was handed. Fix each instance at the tool layer rather than papering over the
symptom.

Execution contract: `Skill: cloud-plan-lane` (see [`../README.md`](../README.md)).
