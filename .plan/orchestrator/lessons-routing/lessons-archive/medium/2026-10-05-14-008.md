# Per-plan scratch artifacts must never live at a fixed shared path

The refine step stages its module mapping at the fixed, plan-independent path `.plan/temp/module_mapping.toon` (refine-workflow-detail.md:752). Two plans refining concurrently overwrote each other's copy — PLAN-13's run clobbered PLAN-12's mid-run. PLAN-12 survived only because later steps read its persisted work copy, not the scratch file.

## Solution

Write per-plan scratch artifacts under the plan's own `work/` directory (or a `.plan/temp/{plan_id}/` subdirectory), never at a fixed shared path in `.plan/temp/`. Check the other phase workflows for the same fixed-path pattern.

## Impact

Silent cross-plan data leak with no error signal; risk grows with parallel plans.

Promoted from truthful-signals inbox `cui-http-quality-report-remediation-013.md` (cui-http PLAN-12, PR #260; orchestrator run observation).
