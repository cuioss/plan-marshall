# Preserve-then-move recovery for pre-plan main-checkout work

component: plan-marshall:phase-2-refine
category: improvement
status: active

## Pattern

When a plan discovers finished work authored on main before the plan existed
(a refine-phase violation), repair rather than discard: capture the pre-plan
diff as a patch artifact, relocate it into the worktree, and re-verify under
the plan's own gates before merging — so no implementation is lost and the
violated gate stays meaningful.

## Provenance

Promoted from process-compliance inbox `phase-gates-008.md`: PLAN-01 was
first authored directly on main; the work was preserved as
`work/preserved-plan01.patch`, moved into the plan worktree, and verified
there (plan phase-gates, PR #1540).
