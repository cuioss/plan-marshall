# Worktree-materialized gate must read authoritative status, persist atomically, fail closed

status: active

## Rule

A persisted readiness flag needs three properties: read the authoritative
copy first and stop (an explicit false must halt the search, never fall
through to a stale record); persist atomically (temp sibling plus
os.replace — `write_text` truncates first and an I/O failure can leave an
empty or partial record); and report success only on read-back (never claim
materialized True unless the persisted flag reads back True; fail closed on
any I/O error other than the expected not-found).
