# Add bulk resolve to manage-findings for triage passes

Source: implement-plan-05-declaration-currency (tooling-truthfulness), PR #1482.

## Problem

Finalize triage of 11 `pr-comment` findings needed 11 single-hash
`manage-findings resolve` calls, one per finding, after the per-finding triage
dispositions were already decided. `manage-findings resolve` addresses exactly
one `--hash-id` per call, so a triage pass disposing a whole finding set pays
one round-trip per finding with no bulk form (274 manage-findings calls in the
plan script log).

## Guidance

Extend `manage-findings resolve` with a bulk form (repeatable `--hash-id` or a
`--type` plus `--resolution` filter) so a triage pass disposes a finding set in
one call.
