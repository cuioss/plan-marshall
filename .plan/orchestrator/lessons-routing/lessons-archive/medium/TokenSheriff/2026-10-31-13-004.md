# Bookkeeping slips: ledger row per out-of-task commit, trailer checked before the first commit, phase transitions left to the orchestrator

## Problem

Three bookkeeping slips cost repair work. (1) PLAN-03: an inline review-fix commit made during finalize triage had no `kind=change` ledger row, so the 5-execute to 6-finalize transition was refused with `execute_commits_unrecorded` until the row was appended. (2) PLAN-07: six unpushed per-deliverable commits carried `Co-Authored-By: Claude Opus 5.5` although the operator required `Claude Sonnet 5.5`; rewriting them left the change-ledger rows pointing at the old SHAs and the same transition refused. (3) PLAN-07: `phase-3-outline` and `phase-4-plan` transitioned the plan's phase themselves, so the metrics boundary was never stamped and was stamped later with the repair time, skewing per-phase figures; a phase-5 leaf also logged under the wrong prefix.

## Solution

Append the `kind=change` ledger row in the same step that creates any commit made outside phase-5 task execution on the plan branch (inline triage fix, review-fix commit, suppression commit). Resolve and check the commit trailer before the first per-deliverable commit, not after pushing. Leave phase transitions to the orchestrator's boundary call so the metrics boundary carries the real time.

## Impact

Refused phase transitions, history rewrites, and per-phase metrics that no longer match what happened.
