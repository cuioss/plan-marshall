content: "# review_completeness check --measured-diff-size is unrunnable on the common path and routes every clean run to loop_back

## Observation

`review_completeness.py check` declares `--measured-diff-size` **without** `nargs='?'`, unlike its
sibling list flags. The generated executor strips empty-string arguments. So the canonical
invocation printed in `automatic-review/SKILL.md` — which interpolates
`--measured-diff-size \"{measured_diff_size}\"` and documents that value as *\"Empty when
unmeasured\"* — becomes a bare flag with no value whenever no size refusal occurred, i.e. on every
ordinary run.

Reproduced verbatim on the first attempt during PR #1410's finalize:

```text
review_completeness.py check: error: argument --measured-diff-size: expected one argument
```

## Why it matters beyond ergonomics

The same `SKILL.md` routes a non-zero exit from `review_completeness check` into the **UNKNOWN**
verdict. UNKNOWN forbids Branch A and forces `loop_back`, with the force-done hatch unavailable.

So as shipped, following the documented invocation converts **every run in which no size refusal
occurred** into a loop_back. The failure is silent in the sense that matters: the operator sees a
loop_back, not an argparse rejection, and the cause is two documents away from the symptom.

Two earlier dispatches in this same finalize independently worked around it by OMITTING the flag
rather than passing it empty — which is the correct move, and is evidence the trap is reachable and
recurring rather than theoretical.

## Directive

Close the gap at the tool layer, not at the call sites. Either:

- add `nargs='?', const=''` to `--measured-diff-size` so an empty value is legal; or
- remove the flag from the canonical block's unconditional interpolation, so it is passed only on
  the refusal path that can supply a value.

Do NOT fix this by instructing callers to omit the flag conditionally — that is a runtime guard
standing in for a contract fix, and it leaves the canonical block still printing an invocation that
fails.

Add a regression test that runs the canonical invocation with an empty `measured_diff_size` and
asserts it does not exit 2.

## Evidence

- `marketplace/bundles/plan-marshall/skills/automatic-review/scripts/review_completeness.py` —
  the `--measured-diff-size` declaration, and its sibling list flags for the contrast.
- `marketplace/bundles/plan-marshall/skills/automatic-review/SKILL.md` — the canonical invocation
  block, the \"Empty when unmeasured\" documentation, and the non-zero-exit → UNKNOWN routing.
- PR #1410 finalize, 2026-09-05: reproduced directly; two separate dispatches had already routed
  around it by omitting the flag."
