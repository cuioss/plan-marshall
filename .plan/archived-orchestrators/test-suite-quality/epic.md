## Vision

The plan-marshall Python test suite (`test/**`) has grown organically alongside 149 marketplace
components and now carries accumulated quality debt: redundant assertions, divergent bootstrapping,
duplicated fixtures, and inconsistent adherence to the `pm-dev-python:pytest-testing` standard. This
epic runs a coordinated cleanup campaign — too large for one plan — to raise the whole suite to a
uniform, standards-compliant, low-redundancy baseline with unified bootstrapping and shared fixtures.

Three coordinated efforts drive it: (1) a **scrupulous analysis** that maps redundancy, fixture
duplication, bootstrapping divergence, and cleanup opportunities across the suite; (2) a **standards
compliance** pass that refactors test packages to the pytest-testing profile standard package-by-package;
and (3) an **adaptation of the test-hardening patterns** already landed by a parallel effort (the
pyproject.toml `timeout = 300` backstop, the pinned pytest/xdist/mypy majors, the
synchronous-seam-over-`asyncio.run` hang fix in commit `283f6dcec`, and the CWE-117 control-char
log-injection regression guards + best-effort-attribution + gc-format round-trip guards in commit
`287b13dd4`) — propagating those patterns suite-wide so the hardening is systemic, not localized to
`test/plan-marshall/build-server/`.

"Done" at the epic level: the analysis has produced an actionable redundancy/fixture/bootstrapping map;
the touched test packages comply with pytest-testing standards; shared bootstrapping/fixtures are unified;
and the parallel-plan hardening patterns are consistently applied where the same failure modes exist.
