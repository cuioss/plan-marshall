# Module-level Path.home resolution without a fallback fails import in restricted environments with no HOME, wrap it in try/except with an env-or-tmp fallback

Resolving `Path.home()` (or `os.environ['HOME']`) at **module import time** binds
the module's importability to the ambient environment having a usable home
directory. In restricted environments — minimal Docker images, sandboxed or
locked-down CI/CD runners, `sudo`-dropped contexts — `HOME` may be unset or
`Path.home()` may raise `RuntimeError`. Because the resolution runs at import,
the failure is an `ImportError`-time crash of the whole module, not a
recoverable error at the call site. Every consumer that merely imports the module
dies, regardless of whether it ever needed the home path.

This slipped every in-house gate on PR #923 (the dev machine always has a HOME)
and was caught only by the PR review bot (gemini-code-assist, MEDIUM) — and it
recurred **twice** in the same PR: `_cred_ensure_denied.py:22` (the module-level
`_HOME_PREFIX`) and `_providers_core.py:49` (`_OLD_CREDENTIALS_DIR`). Two sites,
same anti-pattern, one review pass — a reinforcing signal that this is a class,
not a one-off.

## Root cause

Environment-dependent path resolution was hoisted to module scope for
convenience (compute the constant once), but module scope is exactly where a
failure is least recoverable. A value that depends on the runtime environment is
not a safe module-level constant when the environment is not guaranteed.

## Rule — do this instead

Wrap any module-level home/environment resolution in a try/except with a safe
fallback so import never fails:

```python
try:
    _HOME_PREFIX = str(Path.home())
except Exception:
    _HOME_PREFIX = os.environ.get('HOME') or '/tmp'

try:
    _OLD_CREDENTIALS_DIR = Path.home() / '.plan-marshall-credentials'
except Exception:
    _OLD_CREDENTIALS_DIR = Path(os.environ.get('HOME') or '/tmp') / '.plan-marshall-credentials'
```

Preferred alternatives, in order:

1. Wrap module-level resolution in try/except with an `os.environ.get('HOME')` /
   temp-dir fallback (shown above) so import is total.
2. Better still, make the resolution **lazy** — compute the path inside a
   function/property on first use, not at import — so the import surface carries
   no environment dependency at all.

## Impact

Applies to every marketplace Python script that anchors a path to the home
directory at module scope. Especially load-bearing for the machine-global
home-root work (this plan) and for `marshalld`, which may run in a service
context where `HOME` is not the interactive user's. Grep the changed surface for
module-level `Path.home()` / `os.environ['HOME']` before submit.
