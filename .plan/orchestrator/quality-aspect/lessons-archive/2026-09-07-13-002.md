# The candidate surfacer has no .adoc detectors, so AsciiDoc user documentation is invisible to self-review

## Context

Plan `plan-04-autonomy-gate-defaults` (epic `operator-ux`, PR #1437) added **+76 lines** to
`doc/user/configuration.adoc` — the 25-gate pause-gate census, its largest single documentation
deliverable. The pre-submission self-review ran four rounds and surfaced candidates from the
Markdown and Python surfaces; the AsciiDoc file contributed none, because the candidate surfacer
declares no `.adoc` detectors.

The census was nonetheless corrected during the run — by a *human-authored* self-review finding
(`20608c`) about transitional `keep`/`FLIP` tokens in permanent user docs — not by the detector
set. The mechanism found nothing; a reader did.

## Root cause

The detector families are keyed to file extensions the surfacer knows. `.adoc` is not among them,
so an AsciiDoc file is not scanned rather than scanned-and-clean. The round reports a clean result
over a population that silently excluded the file.

This is the could-not-look-versus-looked-and-found-nothing class applied to the review instrument
itself: the round's zero for that file is not a checked negative.

## Proposed action

1. Add `.adoc` to the surfacer's detector coverage, starting with the detectors that are
   format-agnostic in substance — user-facing strings, stale count prose, same-document normative
   directives, ordinal references.
2. Until then, have the round **name the extensions it scanned** in its own output, so a clean
   result over a change containing `.adoc` reads as partial rather than complete.

## Impact

⛔ This is load-bearing for work already staged. `operator-ux` PLAN-08 (`remediate-user-facing-sites`)
sweeps user-facing prompt sites, and `doc/user/` is squarely in that family; a conformance sweep
measured by a detector set that cannot see AsciiDoc reports a clean result it did not earn. The same
argument the epic already recorded for `_DEF_OR_CLASS` omitting `async def` (`2026-09-02-14-003`)
applies here with a larger blind spot.
