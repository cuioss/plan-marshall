title: "Replace a drifted restatement with a pointer, never with a corrected restatement"
content: "## Rule

When a self-review round finds a **restatement** that has drifted from its declaring source, the
terminating move is to **replace the restatement with a pointer at that source**.

⛔ **Correcting the restatement authors a new claim to audit. Deleting it under-declares the payload.**
Only the pointer removes the thing that can drift.

## Observation

Plan `planning-lane-change-type-scope-execution-manifest` (PR #1399) filed **51** finalize Q-Gate
findings across **19** firings of `pre-submission-self-review`. **Fourteen of the 51 (27%)** carry an
explicit `SELF-SEEDED` / `SELF-AUTHORED` / \"the previous round's own fix\" / \"class-closure miss\" marker
in their own detail text. They form **five chains in which a round's correction authored the next
round's finding.**

The longest ran four consecutive rounds in one file:

- the `failed`→`loop_back` rename left the surfacer-error path with no destination → fix: add Branch C
- Branch C interpolated an unresolved `{sha}`, wedging the round loop → fix: resolve the SHA, **and
  replace the branch *enumeration* with \"every branch\"**, because enumeration is what let a later-added
  branch read as covered
- two more stale branch-set enumerations — *\"the SAME archetype the previous commit's own message named,
  surviving two lines from where that message named it\"*
- two `same_document_contradiction` findings, both in text the same change had just authored

⭐⭐ **A second chain OSCILLATED**: one key-count restatement was fixed by **deletion** in one round and
by **restoration** in the next. Neither move terminated it; only the pointer would have.

## How to apply

1. **Detect the class, not the instance.** A restatement of a count, a key list, a branch set, or an
   enumeration is drift-prone by construction — it has a declaring source and no link to it.
2. **Replace it with a pointer to the declaring source.** Not a corrected count; not a deletion.
3. ⛔ **Beware the enumeration trap specifically.** *\"Branches A, B, C\"* reads as covered after Branch D
   is added. *\"Every branch\"* does not. An enumeration in prose is a restatement of a set that will
   change.
4. **Expect the archetype inside its own fix.** This is the third independent confirmation in this
   corpus that the vacuous/self-seeding class recurs *within the change that fixes it* — see
   [[the n-1-of-n sibling-site archetype]]. **Treat a self-seeded finding as expected, not as a
   surprise**, and check the fix itself before closing the round.
5. **Measure the share.** 27% self-seeded over 51 findings is what made the chains visible at all. A
   round loop that does not tally self-seeded findings cannot tell productive iteration from a loop
   feeding itself.
