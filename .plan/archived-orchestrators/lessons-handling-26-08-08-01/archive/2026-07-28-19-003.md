# architecture-refresh is classified dispatched by the declared single-source-of-truth and inline at two SKILL.md sites; the closure test opens both documents but never cross-checks them

## Status — the named instance is CLOSED

The `default:architecture-refresh` contradiction this lesson was filed against is **fixed**.
`dispatch-inline-split.md` now classifies the step **inline**, carrying the binding mechanism
(its Tier-1 `prompt` mode requires an `AskUserQuestion`, which a dispatched leaf cannot fire);
every `SKILL.md` site that used to restate the inline-only membership now links to that roster
and says "do NOT re-list it here"; and `test_dispatch_roster_closure.py` gained a
cross-document consistency check that reads each step doc's own `This step is **inline**` /
`**dispatched**` self-classification and asserts it agrees with the roster, over a derived
population and behind a mutation guard.

**Do not re-stage the contradiction, the SKILL.md restatements, or the settle-the-question
work — all three are done.** What remains below is the one un-enacted residual.

## Residual — SKILL.md re-enumeration is still un-guarded

The cross-document check compares the roster against each **step doc's own** classification
sentence. It does **not** read `SKILL.md` for an inline-only enumeration. So the specific
assertion this lesson asked for is still open:

> Extend `test_dispatch_roster_closure.py` to parse SKILL.md's inline-only enumerations and
> assert they are absent or roster-derived. The module already holds `_SKILL_DOC`, so this is
> an added assertion, not new plumbing. The population must be **derived from the roster**,
> never a hardcoded step list.

Today the enumerations are gone and replaced by pointers, so the assertion would pass on the
absent branch. Nothing stops a later edit from re-introducing one, and no test would notice.

## Corrective rule (durable)

**When a document declares itself the single source of truth for a classification, no other
document may restate that classification — it may only point at it.** Two documents agreeing
today is not safety; it is two things to keep in sync.
