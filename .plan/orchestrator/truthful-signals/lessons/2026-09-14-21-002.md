# configuration.adoc's per_deliverable_build example uses a retired enum the verb rejects

`doc/user/configuration.adoc`, section "Commit strategy and per-deliverable build
depth" (line 481): the table row for `plan.phase-5-execute.per_deliverable_build`
correctly documents that the value is a LIST of canonical-verify step IDs
(default `[default:verify:compile, default:verify:module-tests]`) and that "the
retired enum strings (off/compile-only/compile+scoped-test/full) are rejected
with a migration error". The runnable example immediately beneath it contradicts
that same sentence:

```
manage-config plan phase-5-execute set --field per_deliverable_build --value compile-only
```

A reader who copies the example hits the exact migration error the row above
warns about.

## The fix

Replace the example value with a list form, e.g.
`--value '["default:verify:compile"]'` (or an empty list to disable the focused
build), matching the documented list contract.
