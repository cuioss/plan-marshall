# Phase-transition artifact gates must require regular files, not mere existence

# Phase-transition artifact gates must require regular files, not mere existence

component: plan-marshall:manage-status
category: bug
status: active

## Rule

Any phase gate checking artifact presence with `glob()` + `exists()` is
vulnerable to directory masquerade: `Path.glob('TASK-*.json')` matches
directories and `Path.exists()` is true for directories, so a
`tasks/TASK-001.json/` directory or an `execution.toon/` directory satisfies
the gate and advances the plan without the required file. Prefer `is_file()`
at every existence check that guards a transition.

## Provenance

Promoted from process-compliance inbox `phase-gates-005.md`: CodeRabbit
finding 878984 (PR #1540, `_cmd_lifecycle.py:243`) showed
`_has_plan_artifact` accepting directories; fixed via TASK-6 (commit
b72e26f4c) with `is_file()` filters plus directory regression cases.
