# Two CodeRabbit nitpicks on PR 1455 need production changes the test-only plan excluded

## Context

PLAN-155 (`close-the-runtime-slice-parametrization`) collapsed tabular test families
into `@pytest.mark.parametrize` across 97 files, all under `test/plan-marshall/**`.
Its spec's Expected Surface states outright: **no `marketplace/bundles/**` file** —
those surfaces belong to sibling plans (WS-03, WS-04, PLAN-130).

CodeRabbit's review of PR 1455 raised seven nitpicks in its review body. Four had
test-only remedies and were fixed in that plan. Three needed a production change
outside the declared footprint, so taking them would have changed the character of
the plan rather than completing it, and would have collided with the sibling plans
that own those files. The `manage-providers` one of those three has since been
closed on its owning surface; the two below remain open and are **not disputed on
merit** — each is a real improvement.

## Directive

Address these two in a plan whose scope includes `marketplace/bundles/**`,
or route each to the sibling plan that owns its surface:

1. **`test/plan-marshall/platform-runtime/test_platform_runtime_router.py:304-316`** —
   the test mirrors the router's operation set as a hardcoded table. The remedy is an
   operation registry on the router's `_dispatch` in
   `marketplace/bundles/plan-marshall/skills/platform-runtime/scripts/platform_runtime.py`,
   which the test then derives from — removing a mirror that goes stale silently when
   an operation is added.

2. **`test/plan-marshall/tools-permission-fix/test_permission_fix.py:1093-1113`** — the
   test rebuilds parser construction inline. The remedy is a parser-construction
   refactor in
   `marketplace/bundles/plan-marshall/skills/tools-permission-fix/scripts/permission_fix.py`
   exposing a builder the test can call, matching the `_build_full_parser()` shape
   `permission_doctor.py` already provides.

The common shape is worth naming: each is a **test mirroring a production set that
production does not expose**. The durable fix is to expose the set, not to keep the
mirror in sync — a mirror is a second source of truth that no gate compares against
the first.

## Provenance

Raised by CodeRabbit on PR 1455, triaged during PLAN-155's finalize. Deferred under
the scope-deviation guard (split-into-follow-up), not rejected: the plan's own spec
excludes `marketplace/bundles/**`, so the deferral is the spec's answer rather than a
judgement about the findings. The PR thread records that they were raised with the
maintainer rather than dropped.
