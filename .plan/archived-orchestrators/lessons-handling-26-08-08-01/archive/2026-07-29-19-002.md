# A negative read of async remote state is provisional exactly as a positive one is

## What happened

A plan reported that its merge was blocked and needed operator intervention. It was not blocked —
`pr auto-merge` had worked. The plan had read `autoMergeRequest: null` from the provider and treated
that single negative read as **definitive**, when it was a stale read of asynchronous remote state
that had not yet settled.

Two findings were filed off that false premise. One is now **rejected-as-contradicted**; the other
narrowed to an open question. The plan corrected itself and said so plainly.

The same run produced the mirror image elsewhere: `absent` reported for a review bot that had in fact
reviewed 75 minutes earlier, and a hard `Recall 0% — FAIL` produced by measuring a worktree that an
earlier step had deleted.

## Why it matters

Teams that get burned by false greens learn to distrust success — and then extend exactly zero of
that skepticism to failure. A red is treated as self-evidently trustworthy because it is
*inconvenient*, and inconvenience reads as credibility.

⭐ **This inverts the usual lesson.** "Do not trust a green" is only half a rule. The real rule is
about **provisional reads**, and it is polarity-independent: a value fetched from a system that
settles asynchronously is provisional **in both directions**, and null/absent/zero are the values most
likely to be the not-yet-settled state, because "not yet present" and "confirmed not present" share a
representation.

A false red is more expensive than it looks. It does not merely waste time: it **manufactures work**.
Here it produced two findings, an escalation to the operator, and four API calls to disprove — all
against a system that was healthy.

## How to apply

- **Treat a negative read of async remote state as provisional.** `null`, `absent`, `0`, and empty
  list are the shapes an unsettled read takes. Before acting on one, re-read after a bounded wait, or
  corroborate against a second source (git, the platform API, the ledger).
- **Ask what the value looks like before it settles.** If "not yet known" and "known to be absent"
  serialize identically, the read cannot answer the question being asked of it, in either direction.
- **Escalate on a corroborated negative, never a single one.** An escalation asserts to a human that
  something is wrong; that assertion deserves the same evidentiary bar as a claim that something is
  fine.
- ⭐ **When you catch yourself trusting a red because it is inconvenient, that is the tell.** Skepticism
  applied only to good news is not skepticism — it is a preference.
- Record the correction when it happens. This one was volunteered by the plan that made the error,
  which is what made the pattern visible across three separate instances in a single day.
