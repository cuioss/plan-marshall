# Dispatching the whole pre-submission self-review as one subagent leaves its verifier step unrunnable

## Pattern

The first pre-submission self-review round was dispatched as a single subagent that ran the entire self-review workflow. The workflow's Step 3b verifier has to be dispatched from the main context. A subagent is a leaf and cannot dispatch, so the envelope had no way to run the verifier, and the round could not close properly. Later rounds split the work correctly: one author dispatch, then a separate verifier dispatch from the main context.

## Rule

- When a workflow has a step that must be dispatched from the main context, the orchestrator drives the workflow step by step. It dispatches only the leaf-capable parts (the author pass, then the verifier pass) as separate envelopes. It never hands the whole workflow to one subagent.
- Before dispatching a workflow wholesale, scan it for any step marked as main-context dispatch only. If there is one, split the workflow at that step.

## Cost

That round's work was spent without a valid verifier verdict and had to be repeated in the split form.
