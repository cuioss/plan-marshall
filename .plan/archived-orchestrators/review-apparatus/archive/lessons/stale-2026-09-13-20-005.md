title: "A validator added because a fail-open default was read as permission must cover every axis that still reaches that default - key, value and container type"
content: "## The rule

When a validator is added because a **fail-open default** (`''`, `None`, `[]`, absent) was being read as permission, that validator must cover **every axis by which the record can still arrive at that default** — key, value, and container type — not only the axis the reporter happened to name.

⛔ **A reviewer's finding is a SAMPLE, never the population.** Treat the named axis as one instance of *\"ways this record can still normalise to the permissive default\"* and enumerate the rest before shipping.

Cheap structural test, applied after adding the guard: *\"what input still reaches the permissive default through this function?\"* If the answer is non-empty, the guard is partial.

## The instance: the fix for a fail-open reproduced the fail-open, one review round later

PR #1477 (`plan-pr-046`), CodeRabbit findings `c36544` (round 1, Major) and `5cf6c5` (round 2, Major) — the SAME fail-open in `bot_registry.py`, found on two different axes one round apart.

The plan's whole purpose was to close a fail-open: `participation_evidence_marker()` returns `''` for an absent key, and `_is_participation_evidence()` reads `''` as *ungated*, so a shape-only comment gets participation credit.

- **Round 1 named the KEY axis.** `_load()` stored any parsed marker key without validation, so a typo (`issue_comments`) silently disabled the gate. TASK-012 added load-time rejection of unknown keys and shipped.
- **Round 2 named the VALUE axis of the identical defect.** The new validator checked only keys, so `participation_evidence_markers: true` — a scalar where a map was expected — hit the `not isinstance(markers, dict)` early return and was treated as the *absent* case; and `issue_comment: true` passed key validation and then normalised to `''`. Ungated again.

## Why it is worth a lesson rather than a bug entry

The second finding is not a new defect. It is the first defect, still open, reached by a different route — and it cost a second review round under a one-review-per-hour rate window to discover. The guard was written against the reported symptom instead of against the default it was defending.
