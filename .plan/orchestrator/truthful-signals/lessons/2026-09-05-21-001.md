# plugin-doctor real-tree test exceeds the 300s pytest-timeout under a bare module-tests run

## Problem

`test/pm-plugin-development/plugin-doctor/test_runner.py::test_argument_naming_blind_spots_are_a_share_of_its_own_population` hits `Failed: Timeout (>300.0s) from pytest-timeout` whenever the suite runs under a bare `module-tests` invocation — whole-tree (24576 passed / 1 failed) and scoped to `pm-plugin-development` (3151 passed / 1 failed) alike.

The same test passes under `verify` on the identical tree.

## Why it is timing, not an assertion

The test calls `runner.run_quality_gate()` over the REAL marketplace tree via `_real_tree_summaries()`. Two reproductions stalled in DIFFERENT frames:

- run 1 — `_analyze_manage_invocation.py:1255`, reading `.md` files
- run 2 — `_analyze_plan_path_in_scripts.py:636`, walking ASTs

So no single hot spot is responsible: the aggregate wall time of a whole-tree quality-gate scan exceeds the 300s per-test budget. Under `verify` the preceding mypy passes have already warmed the filesystem cache for the same tree, so the scan finishes inside the budget; under a bare `module-tests` it runs cold and does not.

## Why this matters beyond one flaky test

`pre-push-quality-gate`'s module-tests divergence arm invokes `module-tests`, NOT `verify`. So the gate is red on a tree whose CI-parity command is green — a finalize-blocking failure that CI would never reproduce. Any plan whose footprint routes through `pm-plugin-development` meets it.

## Directive

Give the test a budget proportional to the work it actually does, or stop making it do whole-tree work:

1. Raise its per-test timeout (a `@pytest.mark.timeout` override) to cover a cold whole-tree scan, OR
2. Cache `_real_tree_summaries()` across the module so one scan serves every consumer, OR
3. Narrow the test to a fixture tree, keeping the real-tree sweep in a separately-budgeted test.

Whichever is chosen, the fix must hold under a COLD run — validate with a bare `module-tests pm-plugin-development`, never with `verify`, whose warm cache is what hides the defect.
