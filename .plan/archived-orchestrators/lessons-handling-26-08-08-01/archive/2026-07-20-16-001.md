# Refine verified a deliverable premise against a standards doc rather than its implementing source, so a stale doc produced an inverted 100-percent-confidence score that only outline caught

## Context

During `merge-queue-coexistence`, phase-2-refine scored the request at **100%
correctness on the first pass** and reported that it had verified deliverable A's
premise. The artifact it verified against was
`tools-integration-ci/standards/github-impl.md`, which stated that the
merge-queue create payload omits `bypass_actors`. The deliverable was scoped on
that basis: add the missing bypass machinery.

The doc was stale. `workflow-integration-github/scripts/github_ops.py` had
**already shipped** full `bypass_actors` machinery. phase-3-outline checked the
premise against the source, found the inversion, and re-scoped deliverable A
before any code was written.

A phase-2-refine Q-Gate finding (`ced433`) had independently flagged the
all-100%-first-pass score as suspicious. That finding was vindicated.

## The defect

phase-2-refine treated a **standards doc as authoritative evidence of current
behavior**. A standards doc is authoritative for *intent* and for the *contract
the project has committed to*, but it is a secondary artifact with respect to
what the code does right now: it drifts whenever an implementation lands without
its mirror doc edit (see `2026-06-29-16-001`, the mirror-contract under-scoping
lesson — this lesson is that lesson's *consumer-side* cost).

Because refine reported the premise as verified, the scoping error was carried
forward with a 100% confidence label attached — the highest-confidence signal in
the pipeline was the one built on the weakest evidence.

## Directive

**When a claim can be checked against BOTH a standards doc and its implementing
source, verify against the source.** The doc is evidence of intent, not of
current behavior. Concretely, at phase-2-refine (and anywhere a deliverable
premise is being certified):

- If a premise is of the form "capability X is absent / present / shaped like Y",
  resolve the implementing module (`architecture which-module`, `architecture
  find --pattern`) and read the source symbol. A doc citation alone does not
  discharge the check.
- Cite the **source location** in the refine output, not the doc location, when
  reporting a premise as verified. A refine report whose only evidence for a
  behavioral claim is a `standards/*.md` path is under-evidenced by construction.
- Where doc and source disagree, the source wins for scoping purposes — and the
  divergence is itself a deliverable (the doc needs the mirror fix).

## Recurrence signature

- phase-2-refine returns an unusually clean score (all-100%, first pass) on a
  request whose premise is a behavioral absence/presence claim.
- The cited evidence is a `standards/` or `doc/` path rather than a source file.
- phase-3-outline or phase-5-execute later inverts or re-scopes the deliverable
  after reading the implementation.

A Q-Gate finding questioning a suspiciously clean first-pass refine score is a
real signal, not gate noise — this run is the instance where honouring it would
have saved the re-scope round trip.
