# Dispatched leaves and operator text point at marketplace/bundles paths absent in a consumer repository

## Defect

Dispatched leaves of `plan-marshall:automatic-review` and `plan-marshall:phase-6-finalize`, and the text they show the operator, name skill documents by `marketplace/bundles/{bundle}/skills/...` paths. The `execution-context` notation table also resolves workflow notations to these paths. Those paths exist only in the plan-marshall source checkout. A consumer repository or its worktree (here plan-marshall-mcp) has no `marketplace/` tree, so every such reference points at a file that is not there.

## Observed

Plan `question-corpus-public-datasets-2`: leaves had to find the skill documents in the plugin cache or in a separate plan-marshall checkout (`target/claude/plan-marshall/skills/...`) before they could follow them. The dispatcher had to give the fallback path by hand.

## Corrective action

Resolve skill-document notations through the installed plugin root (the plugin cache or `CLAUDE_PLUGIN_ROOT` equivalent), not through a path relative to the repository. Or ship a resolver verb that maps `{bundle}:{skill}/{path}` to the absolute installed path and have leaves and operator text use it. Never show a `marketplace/bundles/...` path in a consumer context.
