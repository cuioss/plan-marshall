## What happened

A branch was still labelled "Branch A (empty findings)" — naming, in the label itself, the exact predicate the change had retired one section earlier.

## Candidate rule

A branch label is a normative statement, not decoration. When a branch's selecting predicate changes, the label is part of the change surface; leaving the old predicate in the label leaves a second, contradicting definition of the branch in the same document.
